# Instrukcje dla AI pracującego nad StockEngine

Przed rozpoczęciem pracy przeczytaj plik:

- `docs/project-principles.md`

Projekt jest prowadzony krok po kroku. Przed implementacją wyjaśnij aktualny problem, cel zmiany i sposób jej sprawdzenia.

Nie przechodź samodzielnie do kolejnych milestone’ów ani nie dodawaj nowych technologii bez rzeczywistej potrzeby i uzgodnienia.

Proponuj małe, skupione zmiany. Po każdej zmianie uruchom odpowiedni test lub opisz ręczny sposób weryfikacji.

Przed wykonaniem istotnej zmiany sprawdź aktualny stan repozytorium i istniejącą dokumentację.
